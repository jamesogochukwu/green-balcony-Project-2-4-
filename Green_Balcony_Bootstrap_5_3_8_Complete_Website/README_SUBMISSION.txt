GREEN BALCONY — BOOTSTRAP 5.3.8 WEBSITE
=================================

herbs.html        Herbs growing guide
vegetables.html   Vegetables growing guide
flowers.html      Flowers growing guide

VIEW IT ON YOUR COMPUTER
1. Extract the ZIP file to a folder.
2. Double-click index.html in Chrome or another browser.
3. Connect to the internet so Bootstrap CDN CSS and JavaScript can load.
4. Scroll to 'Explore our growing guides' to see the three-image card group.
5. Scroll to 'New gardener FAQs' and click questions to test the accordion.
6. Open each navigation page and check the illustrations load.

PUBLISH TO GITHUB PAGES (REQUIRED FOR A SITE LINK)
1. Sign in to github.com.
2. Click the + button, select New repository, and name it green-balcony.
   Keep the repository PUBLIC, then select Create repository.
3. Select 'uploading an existing file' (or Add file > Upload files).
4. Upload the CONTENTS of this project folder:
      index.html, herbs.html, vegetables.html, flowers.html,
      tips.html, styles.css, and the WHOLE images folder.
   Do not upload only the ZIP file; index.html must be in the repository root.
5. Commit changes.
6. Open Settings > Pages. Under Build and deployment, choose
   'Deploy from a branch', branch 'main', folder '/ (root)', then Save.
7. Once GitHub shows the published URL, open it and test the FAQ and cards.
   The URL usually looks like:
      https://YOUR-GITHUB-USERNAME.github.io/green-balcony/
   This is an EXAMPLE FORMAT, not a real published link.
8. In Canvas, paste your ACTUAL published website URL. The submission
   requirement is the live LINK, not the ZIP file or a screenshot.

HTML VALIDATION
- Visit https://validator.w3.org/nu/ and enter the published website URL.
- Or visit https://validator.w3.org/#validate_by_upload and upload each HTML page.
- Repeat for each HTML page, not only the homepage.
- Bootstrap's external stylesheet may cause warnings/errors if checking CSS;
  your assignment explicitly says these can be ignored.

DESIGN NOTES
- The site follows the earlier Green Balcony project plan and its
  forest-green, light-green, cream and brown palette.
- The card images are original illustrations stored locally as SVG assets;
  they do not depend on an image hosting service or extra image licenses.
- The site uses educational resource links from university extensions.
- Bootstrap interactive features require the CDN to be accessible online.
- A live GitHub Pages link cannot be created without access to your account.
